CAVEAT — the 'dev' row is a MODEL PROJECTION, not a measurement.
Measured on this same host 2026-10-01: legacy 37 pairs, optimized 62 pairs
(1.7x). The model disagrees because it charges the legacy pair its measured
working set (446.5 MiB, unlimited) while charging the optimized pair its
COMMITTED QUOTA (768 MiB), and it assumes RAM is a hard ceiling. This host
overcommits: macOS compressed ~3.4 GB and ran legacy to 37 pairs = ~16.5 GB
of working set on an 8 GiB machine. On a host without overcommit the RAM
bound would bind and the model would be the better predictor.
For this host, trust docs/before-after-measurements.md over this projection.
